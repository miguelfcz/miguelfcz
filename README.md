## 🧠 Sobre

Estudante de Ciência da Computação (Unipê, conclusão em 2027) com foco em **Engenharia de IA**.
Construo sistemas de IA generativa de ponta a ponta: **RAG híbrido**, **GraphRAG**, **agentes com tool calling/MCP** e **guardrails**, conectados a bancos relacionais, vetoriais e de grafos.

Minha base em dados (Analista de Dados na AeC, com SQL Server, SSIS e Power BI) me dá o que muita gente de IA não tem: sei de onde o dado vem, como ele é modelado e como confiar nele.

<summary><b>⚖️ RAG Jurídico — Hybrid RAG + GraphRAG + Agente + Guardrails</b></summary>
<br/>

- 🔎 **Busca híbrida no Qdrant:** embeddings densos (Vertex AI) + BM25 esparso com fusão RRF, para recuperar artigos e cláusulas que embedding puro erra
- 🕸️ **GraphRAG no FalkorDB:** o LLM extrai entidades e relações de PDF/MD/TXT e monta o grafo de conhecimento
- 🤖 **Agente com function calling:** orquestra SQL (PostgreSQL via MCP), grafo e busca híbrida, mostrando o retorno bruto de cada ferramenta
- 🛡️ **Guardrails de entrada e saída:** mascaramento de CPF/CNPJ e verificação das citações contra os trechos recuperados
